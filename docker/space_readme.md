# GroundedRAG — Aquaculture Advisory Assistant

A citation-grounded RAG assistant for smallholder fish/shrimp farmers, answering
only from a curated corpus of open-access FAO/CGIAR aquaculture guides.
Full source, evaluation harness, and design write-up: see the GitHub repo
linked from the sidebar in the app.
